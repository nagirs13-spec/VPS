VPS案内（スマステ）HTML版

【GitHub Pagesでの公開手順】
1. GitHubで新しいリポジトリを作る
2. このZIPを展開した中身（index.html・opencv.js・dict.json・station.json・plansフォルダ・.nojekyll）をすべてアップロードする
3. Settings → Pages → Branch を main ／ (root) にして Save
4. 数分後に表示されるアドレスを、iPhoneのSafariで開く

・このフォルダの中身をそのまま、HTTPS（暗号化通信）で配信できるサーバー（GitHub Pages など）に置いてください。
・iPhoneのSafariで index.html を開きます。カメラを使うためHTTPSが必要です（ファイルを直接開く方法では動きません）。
・ログはその端末のブラウザ内に保存されます。実験後は管理→ログ→CSV書き出しで必ず取り出してください。
・構内図と辞書が含まれます。公開範囲に注意してください。
